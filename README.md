# REFUGE - SAE S3 groupe 01

Application d'aide à l'orientation des habitants vers les centres d'accueil en cas d'incendie.
Prototype pédagogique, données fictives.

Membres : Aytac Ozan, Duriatti Valentin, Singer Timothée, Maruitte Maël, Boyenval Gauthier

## Lancer le site

```
npm install
npm run dev
```

Puis ouvrir l'adresse affichée (http://localhost:5173).

## Technologies

- Front-end : React + TypeScript, Bootstrap, Leaflet (carte)
- Back-end : PHP 8 (API qui renvoie du JSON)
- Base de données : MySQL
